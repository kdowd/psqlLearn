PostGres Install

We need to install the PostGres database and server onto our Yoobee machines. We can use Scoop an installer that runs from Powershell.

  1. Open Powershell. (PS)
  2. In PS run the following lines:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

    Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

  3. Still in PS Test that scoop is properly installed:

    scoop --version

  4. Now install PostGres with

    scoop install main/postgresql

  5. Finally test PostGres install with:

    postgres --version

  6. You can now close Powershell and from on use GitBash as your CLI
